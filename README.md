# Flight-Data-Analysis
📌 Project Overview

This project focuses on analyzing a structured, date-wise flight booking dataset (For India only) scraped from a popular flight booking website. The dataset contains flight-related information across multiple airlines, providing an opportunity to explore flight pricing patterns, compare airline fares, and identify trends that may help travelers make informed booking decisions.

The analysis was performed using Python and related libraries in Google Colab, covering data cleaning, exploratory data analysis (EDA), and visualization to extract meaningful insights from the dataset.

🎯 Insights found:
1. Number of airlines in dataset and their frequencies
2. Analysis of Departure time and Arrival TIme
3. Analysis of Source city and Destination city
4. Does Price varies by Airlines?
5. Does ticket price change based on the departure time and arrival time?
6. How the price changes with change in Source and Destination?
7. How is the price affected when tickets are bought in just 1 or 2 days before departure?
8. How does the ticket price vary between Economy and Business class?
9. What will be the Average Price of Vistara airline for a flight from Delhi to Hyderabad in Business Class ?


🛠️ Tools & Technologies
Python – Data analysis and manipulation
Pandas – Data cleaning, preprocessing, and analysis
NumPy – Numerical computations
Matplotlib – Data visualization
Seaborn – Statistical visualization
Google Colab – Cloud-based notebook environment


🔍 Project Workflow
- Data Loading: Imported the flight booking dataset into Python using Pandas.
- Data Inspection: Examined the dataset's structure, columns, data types, and statistical summaries.
- Data Cleaning: Checked for missing values, duplicate records, inconsistent formats, and potential data quality issues.
- Exploratory Data Analysis: Investigated datasets to found above mentioned insights.
- Data Visualization: Created charts and plots to communicate key findings effectively.
